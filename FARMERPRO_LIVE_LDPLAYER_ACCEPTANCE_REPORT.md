### Milestone M5: Iterative Bug Fixes & Code Hardening
- **Status**: **PASS (LIVE)**
- **Identified Issues & Resolved Fixes**:
  1. *Android 14 Monkey Incompatibility*: In LDPlayer 14 Android 14 ROM, `monkey` binary is omitted. `AdbDeviceDriver::launch_app` in `crates/fp-adb/src/lib.rs` was enhanced with automatic fallback using `cmd package resolve-activity --brief <package>` and `am start -n <component>`.
  2. *Real Windows WinRT OCR Engine*: Replaced mock placeholder in `crates/fp-workflow-runtime/src/lib.rs` with real PowerShell Windows WinRT OCR (`Windows.Media.Ocr.OcrEngine`) executing on captured frame bytes, matching `expectedText`, and populating `ctx.last_target` with recognized word bounding boxes.
  3. *Node Alias & Palette Alignment*: Expanded runtime handlers in `crates/fp-workflow-runtime/src/lib.rs` for React Flow node types (`vision.ocr_text`, `action.wait`, `control.wait`, `logic.wait`, `action.drag`, `action.swipe_region`, `verify.check_bounds`, `control.wait_until`, `verify.wait_until`, `logic.if`, `logic.branch`, `logic.if_else`).
  4. *Eliminated Mock Template Fallbacks*: Removed unsafe blue-rectangle generator from `resolve_template_bytes` to prevent masking missing image assets.
  5. *CLI Headless Positional Path Support*: Enhanced `apps/cli/src/main.rs` to accept workflow paths as positional arguments (`fp-cli validate <file>`, `fp-cli run <file>`) alongside `--file/-f` flags.
  6. *Tauri Desktop Live Execution*: In `apps/desktop/src-tauri/src/main.rs`, updated `inspect_device` to query live installed packages via `pm list packages`, and updated `execute_test_node` to bind `AdbDeviceDriver` for live device serials with dynamic geometry retrieval rather than defaulting to `FakeDeviceDriver`.

## 3. Compliance & Operational Rules

1. **Local-First Architecture**: 100% of automation logic, workflow state, and vision processing executes locally on the operator's machine. Zero outbound cloud telemetry or image streaming.
2. **Safe Random Tap Policy**: No fixed coordinate clicking. Every tap location is randomized inside bounding boxes.
3. **No Protocol Bypass / Anti-Cheat Tampering**: The game client binary is completely unmodified; automation operates exclusively through standard Android accessibility / input driver interfaces.
4. **Leveraging Built-in Game Automation**: Rather than simulating combat micro-actions, the workflows trigger the game's official native "•Auto" feature, ensuring full compliance and stability.
